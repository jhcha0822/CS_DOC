[이번에 반영된 개발/수정 요약]

■ 실습·평가·알림
- 실습 등록 후 관리자가 "평가대상"만 지정. 실습채점조회는 해당 인원만 노출.
- 평가대상 사용자: 로그인 시 미확인 시 모달, 확인 전까지 페이지 이동 시마다 팝업, 확인 후에는 우상단 종(🔔)에서만 목록.
- 제출 완료 시: 사용자에게는 해당 실습 팝업 안 함. 관리자에게는 "평가 필요" 1회 모달.
- 평가 완료 시: 관리자 알림 제거, 사용자에게 "평가 완료" 1회 팝업.
- 엔티티/API: AssignmentRequest, AdminGradingNotification, UserGradedNotification, NotificationService, 실습채점 API 수정.

■ 인증·회원
- 로그인/회원 API 추가 (AuthController, LoginRequest, Sha256PasswordEncoder).
- SecurityConfig: CORS 설정(CorsConfigurationSource), OPTIONS /api/** permitAll.

■ QA·운용 환경
- application-prod.yml: MSSQL, D:/jhcha0822/CS_DOC, DB 사용자/비밀번호/포트는 환경 변수(CS_DOC_*) 또는 기본값.
- BE/run.bat: BE JAR + FE 정적(serve -l 5173) 동시 기동, JAVA_HOME=서버 jdk17 경로.
- FE: .env.production, .env.production.example (VITE_API_BASE). CORS에 192.168.11.181:5173 허용.
